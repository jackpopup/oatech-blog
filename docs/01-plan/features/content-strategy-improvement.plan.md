## 1. Overview

### 1.1 Purpose

현재 오아테크 블로그 자동 발행 시스템은 기능적으로 동작하지만, 콘텐츠 품질과 전환 효율 측면에서 개선 여지가 크다. 이 Plan은 AI 생성 글의 완성도를 높이고, 검색 의도에 맞는 SEO 전략과 전환율을 높이는 CTA 구조를 정의한다.

### 1.2 현재 상태 진단 (As-Is)

**콘텐츠 품질 평가 - 샘플 글: "펜션 예약률 높이는 5가지 실전 방법"**

| 항목 | 현재 상태 | 평가 |
|------|----------|------|
| 구조 | h2 5개, 흐름 자연스러움 | 양호 |
| 분량 | 약 600자 (목표 1500~2500자 미달) | 미달 |
| 독창성 | 일반적 조언 수준, 실제 데이터 미흡 | 보통 |
| 전문성 | 기본 정보 제공, 숙박업 현장감 부족 | 미흡 |
| CTA 자연스러움 | 섹션 1에 즉시 노출되어 어색함 | 개선 필요 |
| SEO | 메인 키워드 "펜션 예약률" 자연 포함 | 양호 |
| 데이터/출처 | "15~20% 상승" 통계 출처 불명확 | 미흡 |

**주요 문제점:**
1. 실제 분량이 프롬프트 지시(1500~2500자)보다 훨씬 짧음 - AI가 지시를 무시하거나 글자 수 기준을 오해함
2. 실제 현장 데이터, 운영자 목소리, 구체적 수치 부재
3. InlineCTA가 3번 섹션(본문 중간)이 아닌 3섹션 직후 배치 - 전환 타이밍 미최적화
4. 키워드가 13개뿐, 카테고리 간 불균형 (운영팁 5개 vs 사례 2개)
5. 롱테일 키워드 부재 - "펜션 예약률 높이는 법" 같은 구체적 검색어 없음
6. 콘텐츠 형식이 모두 "~가지 방법" 형태, 다양성 부족

## 2. Scope

### 2.1 In Scope

- [ ] AI 프롬프트 개선 (분량 보장, 전문성 강화, 형식 다양화)
- [ ] 키워드 전략 확장 (롱테일, 검색 의도별 분류, 수량 증대)
- [ ] CTA 전환 전략 개선 (InlineCTA 위치 최적화, 맥락 연동)
- [ ] 콘텐츠 포맷 다양화 (체크리스트, 인포그래픽 안내, 사례 인터뷰 형식)
- [ ] SEO 콘텐츠 전략 정의 (검색 의도 4유형 매핑)

### 2.2 Out of Scope

- 블로그 기술 스택 변경 (Next.js, Vercel 유지)
- 발행 자동화 파이프라인 수정 (GitHub Actions 유지)
- 댓글, 뉴스레터, 소셜 공유 기능 추가

## 4. 분석 결과 및 개선 방안

### 4.1 AI 프롬프트 개선 방안

**현재 프롬프트 문제:**
- 분량 지시가 있지만 실제 강제 메커니즘이 없음
- 콘텐츠 형식이 단일 패턴으로 고정됨 ("~가지 방법")
- 숙박업 현장 데이터나 구체적 사례 요청 없음
- 시스템 프롬프트와 사용자 프롬프트 분리 없음

**개선 방향:**

```
[추가할 프롬프트 지시]

1. 분량 강제
"최소 1500자를 반드시 채우세요. 작성 완료 후 본문 글자 수를 직접 세어 확인하고,
1500자 미만이면 각 소제목에 내용을 추가하세요."

2. 현장 데이터 요청
"가능한 경우 구체적 수치(예: 평균 객실 단가, 성수기 가동률 등 공개된 업계 통계)를
인용하고, 출처를 명시하거나 '업계 평균에 따르면' 형식으로 표현하세요."

3. 형식 분기 파라미터
- how-to: "단계별 번호 목록으로 구성"
- checklist: "운영자가 당장 확인해야 할 체크박스 형식"
- case-study: "실제 운영 사례를 가상 인터뷰 형식으로 구성"
- faq: "예상 질문 5~7개를 Q&A 형식으로 구성"

4. 전문가 목소리
"10년 경력 숙박업 컨설턴트가 현장에서 직접 경험한 내용처럼 서술하세요.
'많은 사장님들이...', '실제로 해보면...' 같은 표현으로 현장감을 살리세요."
```

### 4.2 키워드 전략 보완

**현재 문제:**
- 총 13개 키워드, 카테고리별 2~5개로 매우 부족
- 검색 의도 분류 없음 (정보 탐색 vs 구매 의사결정 혼재)
- 롱테일 키워드 없음 - 경쟁 낮은 구체적 검색어 미활용
- 계절성 키워드 없음

**확장 방향:**

| 검색 의도 | 키워드 예시 | CTA 전략 |
|----------|------------|----------|
| 정보형 (Informational) | "펜션 예약률 높이는 법", "모텔 청소 체크리스트" | InlineCTA 후반부 배치 |
| 비교형 (Comparative) | "야놀자 vs 여기어때 수수료 비교", "숙박업 PMS 비교" | 비교표 + InlineCTA 중반 |
| 상업형 (Commercial) | "숙박업 관리 시스템 추천", "펜션 예약 솔루션" | InlineCTA 초반 + BottomCTA 강화 |
| 계절형 | "여름 성수기 펜션 운영 전략", "겨울 비수기 모텔 마케팅" | 시즌 한정 프로모션 CTA |

**롱테일 클러스터 예시:**
```
[메인] 펜션 예약률
  └ 펜션 예약률 높이는 방법 블로그
  └ 성수기 펜션 예약률 100% 달성
  └ 비수기 펜션 예약률 올리기
  └ 펜션 예약 전환율 개선

[메인] 숙박업 객실 관리
  └ 호텔 객실 관리 시스템 소규모
  └ 펜션 멀티채널 객실 관리
  └ 모텔 체크인 자동화 방법
```

### 4.3 CTA 전환 전략 개선

**현재 문제:**
- InlineCTA 메시지가 단일 고정 문구 ("예약 관리, 객실 관리, 매출 분석까지")
- 콘텐츠 맥락과 CTA 메시지 간 연결 없음
- BottomCTA 문구가 너무 일반적 ("숙박업 운영, 지금 바로 시작하세요")
- CTA 클릭 추적 불가 (UTM 파라미터 없음)

**개선 방향:**

```
[맥락 연동 CTA 시스템]

카테고리: 운영팁
  InlineCTA 제목: "지금 이 방법, 시스템으로 자동화할 수 있습니다"
  InlineCTA 설명: "수동으로 관리하던 예약·객실·정산을 오아테크 하나로 통합하세요."

카테고리: 창업가이드
  InlineCTA 제목: "창업 첫날부터 전문 시스템으로 시작하세요"
  InlineCTA 설명: "초기 투자를 최소화하면서 대형 호텔급 운영 시스템을 갖출 수 있습니다."

카테고리: 트렌드
  InlineCTA 제목: "이 트렌드, 오아테크로 바로 적용 가능합니다"
  InlineCTA 설명: "무인 체크인, 스마트 객실 관리 등 최신 기능을 지금 체험해보세요."

[UTM 파라미터 추가]
href={`${SITE_CONFIG.company.url}?utm_source=blog&utm_medium=inline-cta&utm_campaign=${category}`}
```

**CTA 위치 최적화:**
- InlineCTA: 전체 본문의 60~70% 지점 (4번째 h2 직후)
- BottomCTA: 모든 글 하단 고정 (현재 유지)
- 추가 검토: 글 상단 "읽기 전 배너" CTA (트래픽 높은 비교형 글 한정)

### 4.4 콘텐츠 다양화 방안

**현재 모든 글이 단일 형식 ("~가지 방법")으로 생성됨.**

| 형식 | 설명 | 적합 카테고리 | 예상 SEO 효과 |
|------|------|-------------|-------------|
| How-to 가이드 | 단계별 실행 지침 | 운영팁, 창업가이드 | 피처드 스니펫 기회 |
| 체크리스트 | 인쇄 가능한 점검 목록 | 운영팁 | 긴 체류 시간, 공유율 |
| 비교 분석 | 옵션 A vs B 테이블 | 트렌드, 창업가이드 | 상업적 검색 의도 매핑 |
| FAQ 형식 | 자주 묻는 질문 5~7개 | 창업가이드, 법령 | 풍부한 스니펫 구조화 |
| 가상 사례 인터뷰 | "강원도 펜션 대표 인터뷰" 형식 | 사례 | 브랜드 신뢰도, 체류 시간 |
| 계절별 가이드 | 성수기/비수기 특화 전략 | 운영팁 | 시즌 검색량 활용 |

**키워드별 형식 매핑 추가:**
```json
{
  "keyword": "숙박업 객실 관리",
  "format": "checklist",
  "subKeywords": ["청소 관리", "시설 유지보수", "체크인 자동화"],
  "intent": "informational"
}
```

### 4.5 SEO 콘텐츠 전략

**검색 의도 매핑 전략:**

```
[정보형 키워드] - 블로그 주력 영역
목적: 오가닉 트래픽 유입
키워드: "펜션 예약률 높이는 법", "숙박업 후기 관리 방법"
내용: 실용적 how-to, 체크리스트
CTA: 소프트 (본문 후반)

[비교형 키워드] - 전환율 가장 높은 구간
목적: 구매 검토 단계 사용자 유입
키워드: "숙박업 PMS 솔루션 비교", "야놀자 vs 직접예약 수수료"
내용: 비교 테이블, 객관적 장단점
CTA: 미드 포지션 + 강한 문구

[지역형 키워드] - 미개발 영역
목적: 특정 지역 숙박업 운영자 타겟
키워드: "강원도 펜션 운영 노하우", "제주 게스트하우스 창업"
내용: 지역 특성 반영 운영 팁
CTA: 지역 사업자 공감 문구
```

**SEO 기술 개선:**
- 현재 tags 필드가 subKeywords 그대로 복사됨 - SEO 관점 태그 별도 정의 필요
- 내부 링크 전략 없음 - 관련 글 추천 섹션 프롬프트에 추가 필요
- 이미지 alt 텍스트 전략 없음 (현재 이미지 없음)

## 6. Success Criteria

### 6.1 Definition of Done

- [ ] 프롬프트 개선 후 생성된 글이 1500자 이상 달성 (10회 테스트 기준 9회 이상)
- [ ] 키워드 DB 50개 이상, 각 카테고리 10개 이상
- [ ] 모든 키워드에 `intent` 필드 추가
- [ ] InlineCTA가 본문 60~70% 위치에 일관되게 배치
- [ ] CTA 클릭 UTM 추적 구현

### 6.2 Quality Criteria

- [ ] 생성된 글 frontmatter 포맷 오류율 5% 미만
- [ ] 카테고리별 콘텐츠 형식 다양화 (동일 형식 연속 3회 이상 금지)

## 7. Risks and Mitigation

| 리스크 | 영향도 | 발생 가능성 | 대응 방안 |
|--------|--------|------------|----------|
| AI가 분량 지시 무시 | High | Medium | 생성 후 글자수 자동 검증 + 재생성 로직 추가 |
| 키워드 확장 시 품질 저하 | Medium | Medium | 키워드 추가 시 검색량 확인 (네이버 키워드 도구 활용) |
| CTA 변경이 브랜드 일관성 저해 | Medium | Low | 오아테크 브랜드 가이드라인 검토 후 적용 |
| 과도한 SEO 최적화로 글 품질 저하 | High | Medium | 독자 경험 우선, SEO는 부산물로 취급하는 원칙 유지 |
